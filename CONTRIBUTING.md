# Contributing

This repository holds course materials for DATA605 and MSML610 at the
University of Maryland. It is maintained by the course instructor and
invited collaborators only.

## Contribution Policy

- This repository does not accept external contributions
- Pull requests from bots (including automated dependency-update bots,
  spam bots, or AI agents acting without an invited human) are not accepted
- Pull requests from new or uninvited users are not accepted
- Issues opened by bots or by new or uninvited users are not accepted

Any pull request or issue from a bot or an uninvited user will be closed
without review, regardless of its content.

## Why

This is not an open-source project seeking community contributions. It is
class material tied to specific course schedules and grading, so changes
must come from people already coordinating directly with the instructor.

## Who Can Contribute

Only people explicitly invited by the maintainer as collaborators on this
repository can open pull requests that will be reviewed. If you believe you
should have access, contact the maintainer directly instead of opening a
pull request or issue.
