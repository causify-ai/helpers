# Goal
- Given a blog post written in markdown, add visuals (e.g., pictures, diagrams)
  that add clarity and explain the intuition behind the concepts in the post

# Workflow
- Add visuals to the blog following `.claude/skills/blog.rules.md` `# Visuals`
  - `## Add Visuals to Blog Posts`: suggestions
  - `## Types of Visuals`: types of visuals (such as mermaid, graphviz, tikz,
    images, website screenshots)

# Verification
- [ ] Confirm each visual follows `.claude/skills/blog.rules.md` `# Visuals`
- [ ] Confirm each visual renders correctly and matches the surrounding text
